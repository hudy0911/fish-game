# 摸鱼岛 OAuth2 第三方接入文档

摸鱼岛提供标准 OAuth2 授权码模式，允许第三方应用通过用户授权获取用户基本信息。

## 接入流程

```
第三方应用 → 引导用户到授权页 → 用户登录并授权 → 回调携带 code → 换取 access_token → 获取用户信息
```

- 授权页地址：<https://yucoder.cn/oauth2/authorize>
- 后端接口基础地址：<https://api.yucoder.cn>

## 一、注册应用

在摸鱼岛平台创建应用，获取 `client_id` 和 `client_secret`。

创建应用时需填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 应用名称 | 是 | 应用名称 |
| 回调地址 `redirect_uri` | 是 | 多个回调地址用英文逗号分隔 |
| 应用描述 | 否 | 应用描述 |

## 二、授权流程

### Step 1 · 引导用户授权

将用户重定向到授权页：

```
https://yucoder.cn/oauth2/authorize?client_id=fish_abc123def456
  &redirect_uri=https://example.com/callback
  &response_type=code
  &scope=read
  &state=随机字符串
```

参数说明：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `client_id` | 是 | 应用的 Client ID |
| `redirect_uri` | 是 | 回调地址，必须与注册时一致 |
| `response_type` | 否 | 固定填 `code`，默认值 |
| `scope` | 否 | 授权范围，目前仅支持 `read`，默认值 |
| `state` | 否 | 随机字符串，用于防 CSRF，原样返回 |

> 调用授权页前，用户必须已在摸鱼岛登录。

### Step 2 · 换取 access_token

用户授权后，回调地址会收到 `code` 参数，在服务端用 `code` 换取 `access_token`。

- **接口**：`POST https://api.yucoder.cn/api/oauth2/token`
- **参数**（query 或 `application/x-www-form-urlencoded` body）：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `grant_type` | 否 | 固定填 `authorization_code` |
| `client_id` | 是 | 应用的 Client ID |
| `client_secret` | 是 | 应用的 Client Secret |
| `code` | 是 | Step 1 回调中获取的授权码 |
| `redirect_uri` | 是 | 必须与 Step 1 中一致 |

> `client_secret` 仅在服务端使用，不要暴露给前端。

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "access_token": "d41d8cd98f00b204e9800998ecf8427e...",
    "token_type": "Bearer",
    "expires_in": 7200,
    "scope": "read"
  }
}
```

注意：

- 授权码 `code` 只能使用一次，使用后立即失效。
- 授权码有效期 5 分钟。
- `access_token` 有效期 2 小时。

### Step 3 · 获取用户信息

- **接口**：`GET https://api.yucoder.cn/api/oauth2/userinfo`
- **请求头**：`Authorization: Bearer {access_token}`

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "id": "10001",
    "username": "user_account",
    "name": "用户昵称",
    "avatar": "https://example.com/avatar.jpg"
  }
}
```

## 三、错误码

| `code` | 说明 |
| --- | --- |
| 0 | 成功 |
| 40000 | 参数错误（`client_id` 不存在、`redirect_uri` 不匹配、授权码无效等） |
| 40100 | 未登录 |
| 40300 | 应用已被禁用 |
| 40400 | 资源不存在 |

## 四、Node.js 接入示例

```js
// Step 2：服务端换取 token
const res = await fetch('https://api.yucoder.cn/api/oauth2/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({
    grant_type: 'authorization_code',
    client_id: 'fish_abc123def456',
    client_secret: 'your_client_secret',
    code: req.query.code,
    redirect_uri: 'https://example.com/callback'
  })
})
const { data } = await res.json()
const accessToken = data.access_token

// Step 3：获取用户信息
const userRes = await fetch('https://api.yucoder.cn/api/oauth2/userinfo', {
  headers: { Authorization: `Bearer ${accessToken}` }
})
const { data: user } = await userRes.json()
```
